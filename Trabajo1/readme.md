## Descripción

Este proyecto consiste en el desarrollo de una aplicación web básica de gestión de tareas (TODO List) utilizando Node.js, NPM y Express.

La aplicación permite administrar una colección de tareas almacenadas en memoria. Cada tarea cuenta con un identificador, un título o descripción y un estado que indica si se encuentra pendiente o completada.

El proyecto expone la funcionalidad de administración de tareas mediante dos servicios web:

- Una API REST utilizando Express.
- Un servicio SOAP utilizando el paquete `soap`.

Además, se integran herramientas para el registro de eventos, actualización automática durante el desarrollo, análisis estático del código y pruebas unitarias.

## Objetivo

Desarrollar una aplicación web básica utilizando Node.js y NPM, aplicando los conceptos de administración de paquetes y servicios web REST y SOAP.

También se busca integrar herramientas de desarrollo como Log4js, Supervisor, ESLint y Jest para implementar logging, refresco automático, análisis de calidad de código y pruebas unitarias.

## Tecnologías utilizadas

- **Node.js** — Entorno de ejecución de JavaScript.
- **NPM** — Administrador de paquetes.
- **Express** — Framework utilizado para la aplicación web y API REST.
- **soap** — Implementación del servicio SOAP.
- **Log4js** — Registro de eventos de la aplicación.
- **Supervisor** — Reinicio automático de la aplicación durante el desarrollo.
- **ESLint** — Análisis estático y calidad del código JavaScript.
- **Jest** — Pruebas unitarias.
- **Postman** — Pruebas de los servicios REST y SOAP.
- **Git** — Control de versiones.
- **GitHub** — Repositorio del proyecto.

## Requisitos previos

Para ejecutar el proyecto es necesario contar con:

- Node.js
- NPM
- Git
- Postman

No es necesario utilizar una base de datos, ya que las tareas se almacenan en memoria.
